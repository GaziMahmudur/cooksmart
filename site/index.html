🛠️ Android Studio Build Guide

1. Open in Android Studio: File → Open → Select cook-master/flutter_app folder.

2. Sync Dependencies: Run flutter pub get in terminal or tap "Pub get" in the top notification bar.

3. Run or Build: Select your connected Android phone or Emulator and tap the green Run button (Shift+F10).

4. Command Line: flutter build apk --release creates build/app/outputs/flutter-apk/app-release.apk.
